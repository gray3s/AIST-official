# AIST Official

This project is intended to give hard feedback from an agentic AI agent.

The original skeleton was designed to make the agent "hallucinate" and then
have it explain why it did so and what it would do to prevent further
hallucinations. The rules and scope files can be modified to validate the
agent configuration being tested.

You may want to have your agent write its responses to the given prompts to a
single text file for download and review.
